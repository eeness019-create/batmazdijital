# Batmaz Dijital Stüdyo

İşletmelere web tasarım, web geliştirme, logo ve marka kimliği ile grafik tasarım hizmetleri sunan dijital stüdyo için hazırlanmış modern tanıtım sitesi.

## Özellikler

- Güçlü ve mobil uyumlu tek sayfa ajans deneyimi
- Hizmetler, örnek projeler ve çalışma süreci bölümleri
- Özgün Batmaz marka işareti ve editoryal görsel dil
- Netlify Forms ile çalışan proje talep formu
- Başarı, hata ve gönderim durumları
- Erişilebilir semantik yapı ve azaltılmış hareket desteği

## Teknolojiler

- TanStack Start
- React 19 ve TypeScript
- TanStack Router
- Tailwind CSS 4 ve özel CSS tasarım sistemi
- Lucide React
- Netlify Forms

## Yerel Çalıştırma

Bağımlılıkları yükleyin:

```bash
pnpm install
```

Geliştirme sunucusunu başlatın:

```bash
pnpm dev
```

Netlify özelliklerini yerelde emüle etmek için:

```bash
netlify dev --port 8889
```

Form gönderimleri yerel geliştirme ortamında Netlify paneline kaydolmaz; deploy edilen sitede test edilmelidir.
